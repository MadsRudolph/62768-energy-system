# Footprint picks (fiber-laser, through-hole only)

The laser etches a board with track 1.0 mm / clearance 0.8 mm and drills holes after.
Every part is THT, and a few packages need project-specific footprint variants so the
pad-to-pad gaps still meet 0.8 mm. **Always confirm a footprint name exists on disk
before assigning it:** `Test-Path "<libdir>\<Lib>.pretty\<Name>.kicad_mod"`.

Stock libs: `C:\Program Files\KiCad\9.0\share\kicad\footprints`.
Project lib: `hardware\kicad\lib\energy_system.pretty`.

## Standard picks by part type

| Part | Footprint |
|---|---|
| Axial resistor | `Resistor_THT:R_Axial_DIN0207_L6.3mm_D2.5mm_P7.62mm_Horizontal` |
| Film/ceramic 100n | `Capacitor_THT:C_Disc_D5.0mm_W2.5mm_P5.00mm` |
| Electrolytic (≤47µ class) | `Capacitor_THT:CP_Radial_D8.0mm_P3.50mm` |
| Electrolytic 4700µ | `Capacitor_THT:CP_Radial_D18.0mm_P7.50mm` (verify physical Ø/pitch!) |
| Diode (1N400x/1N5817/1N4148) | `Diode_THT:D_DO-41_SOD81_P10.16mm_Horizontal` |
| Zener / small-signal DO-35 | `Diode_THT:D_DO-35_SOD27_P7.62mm_Horizontal` |
| DIP IC (use a socket) | `Package_DIP:DIP-<n>_W7.62mm_LongPads` — **LongPads** is the laser requirement |
| TO-220 (FET, regulator, pass) | `energy_system:TO-220-3_Vertical_LaserPads` — pads narrowed to 1.7 mm so the pin gap clears 0.8 mm |
| Trimmer / pot | `Potentiometer_THT:Potentiometer_Bourns_3296W_Vertical` (assumed — measure the real part) |
| DIP slide switch | `Button_Switch_THT:SW_DIP_SPSTx02_Slide_9.78x7.26mm_W7.62mm_P2.54mm` |
| Power in/out | `TerminalBlock:TerminalBlock_bornier-2_P5.08mm` (or `-3`) |
| Signal header | `Connector_PinHeader_2.54mm:PinHeader_1x<NN>_P2.54mm_Vertical` |
| Wound toroid inductor | `energy_system:L_Toroid_Vertical_L34.5mm_W15.0mm_P28.20mm_LaserPads` (built from caliper measurements; see below) |

## Package rules that bite

- **TO-126 (BD139 etc.) can never meet 0.8 mm** — its 2.28 mm pitch is too tight.
  Substitute a TO-220 part (e.g. TIP41A for a pass transistor, in the shop).
- **Op-amp choice:** LM358 if an input must reach GND (low-side sensing); TL07x can't;
  MCP6002 max 6 V supply.
- The `*_LaserPads` variants are generated by `hardware\kicad\lib\make_laserpads.py`
  from the stock TO footprints (width clamped to 1.7 mm). Regenerate there if needed.

## Custom-measuring a part (e.g. the wound toroid)

When a physical part has no stock footprint — a hand-wound toroid, an odd cap — measure
it with calipers and write a `.kicad_mod` into `energy_system.pretty`. For the toroid
the measurements were: lead pitch = inside gap + lead diameter (e.g. 26.6 mm inside +
1.6 mm leg = 28.2 mm c-c), drill = lead Ø + ~0.4 mm slack (2.0 mm), round pad ~4 mm for
a generous annular ring, body outline = outer diameter. Copy a stock toroid `.kicad_mod`
as the template and edit pad pitch/drill/size + the silk/courtyard rectangle.

## Sourcing

Pick from the shop CSV first (`dtu_component_shop.csv` — its location is per-PC; ask the
user for the path if you can't find it, common spots are their Downloads folder).
Course-kit-only parts (IR2110, IL300, ILD74, MCP601) get footprints from their
datasheets in `docs/datasheets/`. Common substitutions already worked out: LF50→LM7805
(same IN/GND/OUT pinout), 1N5819→1N5817, 1N4007→1N4006, IRF530N→IRF530, BD139→TIP41A.
Record every change in `bom/footprint_map.csv` with the substitution flagged, then
`py -3.13 tools/bom_to_md.py` to refresh `bom/BOM.md`.

## After assigning

ERC should stay at 0 errors. Then dump the netlist and confirm no footprint is missing
or still SMD (`SOIC`, `TSOT`, `SolderWire`):

```powershell
py -3.13 tools\pcb_netlist_json.py "$env:TEMP\b.net" "$env:TEMP\b.json"
# scan the json for null footprints or SMD package names
```
